SOFIVITA — ГОТОВЫЙ ПРОЕКТ ДЛЯ GITHUB PAGES

1. Распакуй архив.
2. Создай репозиторий sofivita с веткой main.
3. Загрузи содержимое архива в корень репозитория, сохранив все папки.
   index.html должен находиться сразу в корне, а не внутри ещё одной папки.
4. Settings → Pages → Source → GitHub Actions.
5. Actions → Publish Sofivita to GitHub Pages → Run workflow.

Подробности, вариант без собственного workflow и подключение sofivita.ru — в README.md.
Фотографии, поезд, рельсы и шрифты уже внутри. Сборка сайта не требуется.

Сам ZIP не заменяет файлы сайта: сначала его нужно распаковать.
